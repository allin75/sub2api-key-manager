# 实施计划

设计依据：`docs/superpowers/specs/2026-09-30-announcement-design.md`（已确认）。

1. 在公告模块定义版本与规则文案，扩展服务端会话视图及确认接口；存储可选确认记录并校验格式，兼容旧状态。
2. 固定托管 Anime.js 4.5.0 和许可证，保持无构建工具与无运行时 CDN 依赖。
3. 将原公告替换为顶部入口和原生强提醒对话框，实现保存后收缩、手动重看、失败重试和退出。
4. 整理登录与恢复会话的加载反馈、动画顺序、重复提交保护和过期中断。
5. 补充服务端、存储和界面测试，运行全部 Node 测试和逐文件语法检查。
6. 用本地假数据检查桌面、手机及减少动画模式，保存截图；更新 README、CHANGELOG 与交接记录，提交并推送 GitHub main。不自动部署 NAS。
