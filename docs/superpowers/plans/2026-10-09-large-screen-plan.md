用户已确认保留双列的推荐方案。范围为现有前端阅读尺寸和预览定位，不涉及业务接口或生产数据。

1. 将内容尺寸从 px 转为 rem，保留原 CSS 媒体断点和细线尺寸。1080p 默认 16px 根字号下与现有尺寸一致。
2. 增加 1920px 以上的流式根字号及容器宽度；2560px 对应 20px / 1560px，3840px 对应 24px / 2200px。
3. 七天预览从实际根字号推导首选宽度，保持外侧空间不足时下方展开的回退行为；补充边界定位测试。
4. 用本地纯假数据进行多分辨率、缩放等效视口、公告动画和预览验证，保存截图。检查 SVG 坐标系文字及图标尺寸。
5. 运行全部测试、语法检查和差异检查，更新缓存版本、变更记录及交接记录，提交并推送 GitHub main。当前 NAS SSH 不可达，保留未部署状态。
