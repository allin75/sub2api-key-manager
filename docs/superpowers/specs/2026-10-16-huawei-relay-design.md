# 华为云备用网页入口

## 已确认范围

用户已确认保留 NAS 管理程序和 Cloudflare Tunnel 入口，新增经华为云直达 NAS 的 HTTPS 入口；新域名为 `key-direct.1501129.xyz`。不迁移业务数据，不修改 Key、额度、调度或其他 NAS 服务。

## 连接方式

浏览器通过仅 DNS 的 A 记录访问华为云，Caddy 终止 HTTPS，再经云端 `127.0.0.1:13100` 进入 NAS 主动建立的 SSH 反向隧道，最终访问 NAS `127.0.0.1:3100`。

对比方案：继续经 CF 回源不能绕开原瓶颈；独立 FRP 需要另外开放连接端口；专用 SSH 隧道可以复用已开放的 22 端口，适合单个低流量网页。采用后者。云端使用仅允许反向转发到指定回环端口的独立账号和密钥，禁止交互会话及其他转发。NAS 使用独立 Docker Compose 服务，配置只读密钥、无额外权限、自动重启和保活。云端 Caddy 作为系统服务自动申请及续期证书，覆写转发来源头，保留外部 Host 和来源校验，不缓存管理接口或登录状态。

## 环境核对

华为云 `cn-east-3`，Ubuntu 24.04，2 核 / 2 GiB / 40 GiB，控制台显示峰值带宽 2 Mbit/s、100 GB 流量包，已有入站 TCP 80/443 规则。NAS 应用运行 `1.3.4` / `5dd98e7` 且 healthy。NAS 到云端 TCP 建连约 7 ms。此数值不等于完整页面耗时；最终需同时测新旧入口。域名接入及证书必须实际验证，遇到供应商备案拦截则如实记录并保留原入口。

## 验收与回退

验证新域名解析至云端、公开可信证书、页面和静态文件与 NAS 一致、未登录接口仍为 401、来源校验保持有效；使用真实账号验证时仅登录和读取缓存，不触发同步或业务写入。验证隧道重连、容器重启后的连接恢复、Caddy 自动启动与续期配置，确认其他容器没有重建、应用提交未变。截图只记录登录页或 DNS 配置，不提交真实业务数据。

变更前在两端单独保存部署基线和涉及配置。回退仅停止新隧道容器、移除新入口配置及新增 DNS 记录，保留所有业务数据与既有 CF 隧道。失败时不要以跳过证书校验或明文登录作为正式交付。

## 实施顺序

1. 保存云端及 NAS 基线，创建专用隧道密钥与受限云端账号。
2. 构建 NAS 专用 SSH 客户端容器，连接回环端口并检查响应。
3. 新增仅 DNS 记录，配置 Caddy HTTPS、自动续期及来源头。
4. 验证新旧入口、重连、权限边界及浏览器页面；记录实测耗时。
5. 更新部署说明和项目交接记录，提交并推送。
