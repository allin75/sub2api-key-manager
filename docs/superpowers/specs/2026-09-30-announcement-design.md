# 强提醒公告与登录过渡

用户已于 2026-09-30 确认以下设计，实施范围不包含 NAS 部署。

## 交互

- 登录或恢复会话后，未确认当前版本公告的账号必须看到模态公告。首次提醒不能通过遮罩、Esc 或关闭按钮跳过；根据本地反馈，公告弹窗不提供退出按钮，退出仅在顶部导航栏提供。
- 公告沿用额度规则，分项说明周刷新、月刷新、体验额度、奖励和实际消费口径。
- 点击“我已知晓”时先保存确认记录。保存失败保留弹窗并允许重试；保存成功后卡片收缩至顶部导航栏的公告入口。
- 公告入口常驻，与修改登录密钥、退出登录共用顶部导航栏。已确认后再次查看可关闭，不重复写入确认记录。
- 确认按账号身份与公告版本保存到服务端。普通账号使用稳定 ID，改密钥或换浏览器不会重复提醒；超级管理员单独记录。新公告版本重新提醒。
- 不继承旧公告的浏览器关闭状态，取消三天自动过期。

## 动画与可访问性

- 本地托管 Anime.js 4.5.0 固定版本和 MIT 许可，复用 createLayout 的跨父元素布局过渡。运行时不依赖 CDN，不放宽现有内容安全策略。
- 登录卡片入场、提交反馈、进入管理页和公告出现按顺序执行；恢复已有会话不闪现登录表单。
- 原生 dialog 提供焦点约束；弹窗内容可滚动，手机适配，关闭后焦点回到顶部入口。
- 尊重 prefers-reduced-motion；动画库不可用时直接完成状态切换。退出或会话过期时取消旧动画和待处理界面操作。

## 边界与验收

- 不改变 Key、额度、预算、奖励与调度逻辑，不增加前端框架。
- 确认接口使用现有会话、CSRF 和独占写入队列，拒绝旧版本确认并保证重复提交幂等。
- 测试覆盖账号隔离、版本变化、密钥改名、服务重启、保存失败、强提醒关闭约束和减少动画模式。
- 核验桌面、手机、刷新会话、手动重看、退出登录及动画中断。

## 本地反馈修正

- 2026-09-30：用户要求修复收起末段的闪屏、关闭图标偏心，并移除公告内的退出按钮。
- 遮罩淡出完成后不立即恢复不透明状态，等待布局过渡完成后先隐藏再清理样式；取消动画仍正常恢复样式。
- 关闭按钮清除继承的内边距，使用居中的 16×16 SVG 图标，保留原有键盘焦点与可访问标签。
- 弹窗操作区仅保留确认或收起按钮，靠右对齐；不改动顶部导航栏的退出功能。
- 2026-09-30：本地复现公告锁定背景滚动时页面增宽 15px，关闭后恢复导致横向晃动。根元素持续设置 `scrollbar-gutter:stable`，保留背景滚动锁定与原有收缩动画，不增加补偿脚本。桌面有/无滚动、短屏、窄屏、减少动画模式逐帧检查页面和公告入口横坐标、宽度不变，手机覆盖式滚动条不增加占位。
- 2026-09-30：根据入口图标突然出现的反馈，收缩过程中保持入口内容透明，卡片落到导航栏后以 180ms、`inOut(2)` 曲线将入口透明度从 0 过渡到 1、缩放从 0.88 过渡到 1。仅在动画层内禁用通用按钮 CSS 过渡，防止双重缓动和末帧跳变；显示完成后再收尾并恢复焦点，退出或会话切换时取消并清理临时样式。减少动画模式和库不可用时直接显示，保留原有遮罩淡出与滚动条占位。
