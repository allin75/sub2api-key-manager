# 最近七天用量预览

用户已批准：两列 API Key 用量卡片悬浮预览，点击固定。复用已有实际消费日统计，不增加悬浮请求。

- 含今天的北京时间最近七天，补齐无消费日期；保留原有期间汇总。未同步的旧缓存显示占位，失败缓存明确标注。
- 停留 180ms 打开，离开 200ms 后关闭，允许穿过 12px 间隙进入浮层。一次显示一个浮层，固定后其他卡片悬浮不会替换内容。
- 浮层跟随来源卡片高度，侧向展开时上下边缘严格对齐，内部图表弹性填充空间；纵向展开时高度不超过视口。
- 左列向左、右列向右展开。侧边不足时改为下方，底部不足时上方，并约束在视口内；手机点击操作。
- 点击固定，再次点击、空白区域或 Esc 关闭。支持卡片键盘 Enter/空格和图表数据点聚焦。内部按钮保持原行为。
- 220ms 方向位移配合淡入，550ms 折线绘入；固定时不重复播放。尊重减少动态效果设置。
- 标题移动超过 6px 才进入拖拽；拖拽后抑制误点击。自动刷新保留固定卡片，切换账户或退出登录关闭浮层。
- 每日明细由 utils.js 纯函数处理，sub2api.js 随现有统计返回；界面状态放在 app.js，样式使用 usage 前缀。

验证：日期跨月/跨年、闰日、缺失日期、重复日期聚合、HTTP 明细传递；模拟数据浏览器验证左右方向、悬浮跨越、固定/关闭、键盘、按钮兼容、标题点击与窄屏边界。不得连接生产账号测试。
