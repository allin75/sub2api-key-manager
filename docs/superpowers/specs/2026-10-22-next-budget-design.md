# 原额度设置与下一期额度

用户已通过本地交互预览确认去掉“单独设置”开关，并授权实施、同步 GitHub 和部署 NAS。

- 保留现有深蓝配色，额度类型使用自定义深色下拉菜单，支持键盘、选中勾号与外部点击关闭。金额框使用固定显示的同风格 SVG 上下键，沿用 0.01 USD 步长。
- 本期额度保存后立即生效，同类型修改不清空已用额度；下一期额度默认显示已保存的下一期金额，否则显示本期金额，不使用额外开关。
- 月刷新开启时，下一期金额在下次北京时间月初刷新生效，成为后续默认额度；月刷新关闭时保留预约但不执行，恢复月刷新后从下一次刷新生效。体验模式隐藏下一期输入，切换为体验模式清除预约。
- 可选 budget.nextLimit 持久化到各账号预算。老数据无该字段时继续沿用本期金额，旧 API 请求不传该字段时保留已有预约。下次月刷新先应用预约，再沿用现有账本和 Key 恢复所有权规则。
- 保存携带打开时的月份，跨月旧表单拒绝并提示重新打开。保存过程中锁定表单、保存目标和重复请求；失败保留输入，异步旧会话响应不得关闭新弹窗。
- 不修改上游配额接口、奖励、卡片定位、光效、网络或其他服务。测试只使用假数据；发布保留原 .env、Compose 和数据卷，备份后定向切换且具备回退。

验证覆盖金额边界、月初/跨年、跳过月份、重启、失败/冷却重试、月刷新开关、体验切换、账号隔离、旧数据与接口兼容，及桌面/手机、键盘、保存失败和重复提交。
