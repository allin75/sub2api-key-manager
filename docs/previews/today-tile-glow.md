## 循环重置修复

用户随后报告转完一圈、再转半圈会停一下重来。浏览器复现确认是预览缓存预算未提供 `error`，但状态接口返回 `error: null`，导致现有五秒轮询每次误判数据变化、重建卡片并重启动画；不是 CSS 一圈本身有停顿。

- 将纯假数据服务收录为 `docs/previews/today-tile-preview-server.mjs`，缓存与状态接口显式共享 `lastSuccessAt`、`error: null`、`rateLimitedUntil: null`，避免无变化时重建。
- 金红两个绕边计时改由持续存在的 `#keyGrid` 承载，小格通过可继承的角度属性获取相位，即使正常刷新重建小格也不重头转。样式及速度不变，减少动画时停止外层时钟。
- 新增 Node 回归测试锁定接口一致性和计时归属。浏览器连续采样 16 秒，金色三次/红色五次跨周期，无自动重建或不连续跳跃；强制重建一次后，时钟对象与角度保持连续，减少动画通过。
- 正式 `public/`、后台 `src/` 与 NAS 不变。

在仓库根目录运行 `node docs/previews/today-tile-preview-server.mjs`，访问 `http://127.0.0.1:3115/?preview=motion-fixed`。预览仅监听本机，所有数据为假数据，写入请求返回 405；不加载生产环境配置。

## 昨日五秒渐弱提醒

用户继续要求「昨日」也增加特效，但只播放约五秒，从强到弱自然结束。

- 仍按未四舍五入金额 > $10 金色、> $20 红色；≤ $10 或缺失数据不触发。预览服务仅在响应中为周期格添加原始数值属性，正式 `public/app.js` 不变。
- 每次打开页面、首次展示每个 Key 的昨日统计时播放一次，总长 5 秒含淡入淡出。约 0.4/1.8/3.2 秒的三个柔和峰值依次为 1/0.62/0.3，最后归零；不做快速闪烁或循环。
